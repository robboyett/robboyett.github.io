TabClear

Chrome extension that closes every tab and saves an organised HTML archive before you start fresh.

Tab overload is a familiar problem. TabClear closes all open tabs in one click — but first saves every URL, title, and favicon into a searchable HTML report grouped by domain. Nothing lost, browser cleared.

The popup is deliberately playful: a bold action button with a drink icon, starburst animation on hover, and Inter typography throughout. The generated archive opens in a new tab so you can search, revisit links, or save the page for later.

Built as a Manifest V3 Chrome extension. Load unpacked in developer mode to try it locally.
