MD ↔ FigJam

Figma plugin to import markdown into sticky notes and export selections back to clipboard-ready markdown.

A FigJam plugin for the workflow where notes, docs, or AI output need to land on a whiteboard fast — and come back out as markdown when the session is done.

Import multiple sticky notes from markdown with colour tags ([Red], [Yellow], etc.), bold text, links, and bullet lists. Export selected stickies back to markdown with auto-copy to clipboard. Handy syntax: / starts a new note, [Color] sets the colour for following notes.
