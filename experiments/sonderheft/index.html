Sonderheft

Swiss-style ordered dither backgrounds for the web — homage to TM Sonderheft Nr. 3 (1986).

Coloured type fields that dissolve into paper through a Bayer matrix, not a smooth gradient. One script, zero dependencies — add the dither class to any element and configure via CSS variables, data-dither JSON, or Dither.apply().

Named after the German word for "special issue" on the cover of Typografische Monatsblätter, Nr. 3 (1986) — cover design by Heinz Hiltbrunner, devoted to Armin Hofmann, set in Univers.
