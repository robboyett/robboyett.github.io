UX & Research Insights for VS Code

Surface UX research markdown directly in your codebase — sidebar, status bar, and rich preview.

An engineer-friendly VS Code extension that auto-discovers research folders, highlights insights relevant to the file you're editing, and opens markdown in a readable webview panel. The goal is to keep design context in the flow of work — not buried in a wiki nobody opens.

Research lives alongside the code it informs: versioned, searchable, and visible when it matters. As AI-assisted coding becomes normal, that proximity becomes structural — intent, trade-offs, and evidence travel with the implementation.
